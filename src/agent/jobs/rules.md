# Rules

1. Work in the owner's own Microsoft Edge. Open its own Edge window for this job and leave the owner's other tabs alone. Never open Chrome or another browser.
2. Open only the URLs listed under "URLs you may open"; open no other page and do not search the web. Following the file or attachment links on a listed page in order to download what this job names is allowed only when they stay on this Canvas course (its files); never follow a link to another site (Gradescope, Google Drive, Echo360, Readings Online and the like), even when it looks like a file.
3. If a sign-in page, password field or multi-factor prompt appears, do not sign in: stop, then make only the fallback call this job names, if any. Never type a password, passcode or code.
   A browser-tool error (an unsupported option, a window that did not open, a key press that did not register) is not a sign-in page: retry once in a plain new Edge tab or window without extra options, and make the fallback call only if a sign-in page then appears.
4. This job is read-only apart from the save or download it names. Never submit, post or press a button that changes something; never reply, upload, enrol or delete.
5. Only tool calls count: never claim in text that something was saved. Call the tools named in this job.
6. End after the one output tool call; for the course list, after `courses.offer` when it is used.
