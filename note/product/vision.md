# 产品愿景

> **v1 文档。** 2026-10-29 起以 v2 为准（#223）；「代码不调用模型」（#123）已不成立，进度以 [路线图](roadmap.md) 为准。

> 2026-10-15：范围、用户故事和验收标准以 `prd.md` 为准；本文件和它冲突的地方（如「代码不调用模型」#123、考试的代码检查 #126、等级定义 #120、禁止 AI 的课锁在 L0 #124）以 `prd.md` 为准。

- **这是什么：** 以课业为核心的个人行动中心。墨大的 Canvas、Ed 自动接入（iCal 已去掉，#77），学校之外的事（找实习、游戏等）按模块手动管理，统一排进每周计划。
- **给谁用：** 我自己（墨大学生，同时在找实习）。仓库在自动作答 / 提交的代码（L1/L2，#120）推送前转为私有（#57），只供自用。
- **要解决的核心问题：** 课程信息分散在 Canvas 和 Ed；作业、权重、截止时间靠手动抄进 Excel；截止时间被改了发现不了；每天做什么靠脑子排；分数要自己算。
- **四个优点（决策 #26，第 4 条来自 #56、#70）：**
  1. **自动**：作业、权重、日期、分数自己长出来、自己更新，有变化主动提醒。
  2. **可信**：拆出的每一步都附原文出处，逐字核对过。
  3. **排得动**：按截止时间和每天可用时间排成每周计划（#65），排不下的提前标出。另附成绩推算。
  4. **省时间**（#56、#70）：考前自动整理复习资料和模拟题，在我们的前端学习和对话；按课程 AI 政策分级代做（L0 只读 / L1 quiz / L2 assignment 和论文，#120）；考试不在代做范围（AI 做不了，#126）。
- **成功长什么样：** 下学期我不再手动做那张 Excel。辅助指标：同步成功率、抽取准确率（用自己标注的评估集测）、预计和实际用时的偏差。

## 明确不做

- 不做笔记或知识库编辑（Notion 只读集成挪到第二版，#71）。
- 我们的代码不直接调模型 API、不存 API 密钥，只启动用户已登录的 agent（#123，修改 #13、#72）。
- 考试不代做（不单设代码检查，#126）；课程 AI 政策为「禁止」的课锁在 L0（#124）。
- 不做多用户线上服务；数据只留在本机。
