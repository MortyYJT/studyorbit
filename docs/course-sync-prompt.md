# 单课程同步提示词（草稿）

日期：2026-10-28。此文档供用户审阅和后续调整，尚未接入程序，也尚未经用户实测。

## 调度约定

点击同步后获取课程列表；用户选择并保存课程后，自动继续同步所选课程。每门课一个 Codex subagent，使用 Luna，按课程顺序执行，同一时刻只运行一个课程读取任务。程序提供课程名称、课程代码、Canvas 课程链接、学期和该课程的目标文件夹。课程之间不共用正在操作的浏览器窗口任务。

每个课程任务使用自己新建的 Edge 标签页，不借用其他 agent 已绑定的标签页；任务完成后释放自己的页面。Ed 先从首页课程列表点击对应课程，不能把直接打开的加载界面当作已读到课程。

这是目标流程，不代表当前项目已经支持自动派发、模型选择或电脑操作；实现方式和跨平台兼容性尚待验证。

## 页面处理规则

这些规则参考旧架构图「分层同步 v0.3」，并按用户近期决定更新：只使用 Canvas LMS 和 Ed，不使用 Handbook；Lecture Capture、Gradescope 和 Readings Online 不读取。2026-10-28 用户调整：同步时不下载任何文件，操作失败最多尝试 2 次。

| 页面 | 处理方式 |
| --- | --- |
| Canvas 课程主页 | 读取课程内容、作业和大纲分别在哪里；课程主页上指向课程信息的链接可继续查看。 |
| 评分、作业列表 | 获取考核分组、权重及可见的作业、分值、成绩、状态和截止时间。 |
| 测验列表 | 读取说明、开放时间和截止时间；区分计分测验、调查和练习。不得进入正在作答的测验或提交。 |
| 大纲 / Subject Overview | 可读取并记录链接；如果课程指向 Ed，则在 Ed 查找课程大纲。不下载文件，不使用 Handbook。 |
| 单元 / Modules | 查看教学和作业目录、记录相关教学资料链接；作业仅获取表层字段和链接，不下载文件。 |
| Ed | 如果课程有 Ed 且用于教学或作业，则读取课程信息、教学和作业目录与考核表层信息，并记录相关教学 lessons、slides 的链接，不下载文件；作业内容等用户点击开始后再获取。没有 Ed 就跳过。 |
| 页面 / 文件 | 不遍历整个栏目；课程主页或相关目录明确指向时，查看并记录相关教学文件链接，不下载。作业要求和附件延后获取。MUSI20163 主页明确指向 Files。 |
| 作业详情 | 同步阶段只获取作业名称、链接、开放与截止时间、分值、占比、状态等表层信息；没有明确值时标未知。正文要求、评分标准、AI 政策、代码、图片和附件等用户点击“开始学习”后再获取。 |
| 公告、讨论 | 同步阶段不读取；不要因为 Ed 名称带 Discussion 就跳过它的教学和作业区域。Ed 点课程后如果默认落到讨论页，直接切换“课程”，不读取或操作讨论内容。 |
| Lecture Capture、Gradescope、Readings Online、Echo360、Zoom、人员、协作、结果、Office 365、Google Drive | 不打开、不读取。用户已明确 Lecture Capture 也无用，因此不按旧图保留其链接。 |

用户点击“开始学习”后，才获取该作业的详细要求、评分标准、AI 政策、代码、图片和附件；此后续流程尚未实现。具体能否完整获取需要用户在真实课程测试，不能提前宣称已完整保存。

## 四门课截图带来的判断

- **COMP20003**：主页明确表示课程内容在 Ed，Canvas 用于跳转和保存成绩；优先找 Ed 课程内容，同时读取 Canvas 评分和测验。截图没有列出全部 Ed 内容，具体仍以页面为准。
- **MAST10007**：主页明确说 Canvas 是课程资料库，lecture notes、Exercise Booklet 和 tutorial 等资料有单元入口；导航中也有 Ed。只凭截图不能判断 Ed 内容是否与 Canvas 重复。
- **MUSI20163**：主页指向 Subject Overview、Modules 和 Files，明确 Files 包含可下载的音频和 PDF；截图中没有 Ed 入口，不能据此断言课程绝对没有 Ed。
- **COMP20008**：导航中有 Modules、Ed、评分、测验、作业；截图不足以判断具体内容如何在 Canvas 与 Ed 之间分工，应读取课程主页和相关入口判断。

以上是导航示例，不是对所有课程的固定规则。课程间应以实际主页、导航和用户可访问的页面为准。

## 提示词模板

```text
你是课程信息读取员。使用用户已登录的常用浏览器，对下面一门课进行只读同步。

课程：{course_name}
课程代码：{course_code}
学期：{term}
Canvas 课程地址：{canvas_url}
课程文件夹：{course_dir}

任务：
1. 使用该任务新建的浏览器标签页打开课程主页，不借用其他任务已绑定的标签页；
   判断课程内容和考核信息分别在哪里，是否有 Ed。需要 Ed 时先进入 Ed 首页，
   从课程列表点击对应课程；记录实际访问路径和是否成功打开。
2. 查看可用的评分、作业列表、测验列表、大纲与单元目录，整理考核结构。
   Ed 被课程用于教学或作业时，也查看对应课程的教学和作业目录；没有就跳过。
3. 将考核分组、已明确的权重、考核名称、类型、开放和截止时间、满分、
   已出成绩及状态整理到 {course_dir}/分数结构.json。记录每个信息的来源链接；
   关键判断保留原文依据。页面没有明确写出的值标记为未知，不能猜测。
4. 记录相关课件、教材和其他教学资料的名称及原始链接；不下载任何文件。
   记录无法读取的资料及其链接。
5. 对作业只获取表层字段和原始链接。不要读取或保存作业正文、评分标准、AI 政策、
   作业代码、图片和附件；等用户之后点击“开始学习”时，再获取具体作业内容。
   不提前解题或完成作业。
6. 浏览器读取完毕后关闭本任务自己创建的 Canvas 和 Ed 标签页，不关闭用户原有标签页；
   然后只使用已经读取到的信息整理结果，不再使用浏览器。关闭失败须记录，不得反复操作。

分类：考试、测验、作业（含论文/报告/项目）、展示、参与、不计分。
每个考核项目的“分类”只使用上述六类；依据不足时写“未知”，保留原始类型和来源，不因为权重缺失而认定为 0%。组权重和单项权重分别记录，不把分组的 0% 自动当成每个单项的权重。
练习、调查、Token 申请和仅供反馈的条目不要默认当成计分考核。
分值不等于课程占比；没有明确证据时，不要把满分换算为占比。
原样记录评分组，不凭名称或加总猜测组与组之间的父子关系；存在冲突时记录两处来源，标待核。
整理最终列表时主动判断：Canvas 和 Ed 对应同一考核时合成一条，保留两边链接和依据；把分数组作为结构信息，不再把同名分数组当作另一个作业。综合名称、课程、截止时间、内容入口及页面说明判断，不要求用户逐项合并。区分有实质差异的不同作业；证据不足无法决定时保留来源及未知，不编造。普通考试和 AEA、延期或特殊安排的考试若是替代版本，只在主要列表安排用户适用版本；适用性不明的版本保存于原始记录，不重复生成排期。
直接输出对排期有用的精简考核清单，按测验、作业、考试、展示、参与排列；普通参与、不计分和零占比项收起。有明确 hurdle 的参与项目保留。不要把预定跳过的内容、不相关入口或重复的状态作为问题展示给用户。

不要读取公告和讨论；若 Ed 选课后默认进入讨论页，直接切换“课程”，不要阅读讨论。
不打开 Lecture Capture、Gradescope、Readings Online、
Echo360、Zoom、人员、协作、结果、Office 365 和 Google Drive。主页或相关目录
明确指向的页面/文件可以查看；不遍历无关页面或文件。不要访问 Handbook。
只读，不提交、不作答、不修改课程内容。遇到登录页面时停止该来源并报告。
不要清空、覆盖或删除用户已有文件；有同名冲突时保留两份并报告。
任何操作失败时最多尝试 2 次，仍失败则记录原因并继续，不反复点击或下载。

JSON 暂按以下顶层字段组织：课程、同步状态、来源、考核分组、考核项目、
课程资料、未能获取。无法确认的值为 null，并在未能获取中说明原因；
每项资料包含名称和原始链接。时间保留页面原文与来源，无法确认时区不要猜。
成绩、分值、权重各自记录，未知不得替换为 0。规则为试运行草稿，不代表最终格式。
作业正文及附件等按本任务规则主动跳过的内容，不属于失败或缺失；不能仅因没有获取
这些不在同步范围内的内容，就把课程标为部分完成。实际未读到的目标信息应标明原因。

完成后返回：
- 课程代码，完成 / 部分完成 / 失败；
- 分数结构 JSON 的路径、已发现的课程资料名称和链接；
- 每个无法读取或保存的项目、原因及原始链接；
- 需要用户处理的登录或访问问题。
```

JSON 的最终字段格式、资料链接记录方式及运行耗时需要用户根据试运行结果确定；不能以提示词本身视为实现保证。开始学习后获取作业代码和图片的方式另行设计。
