# 课程分析提示词

同步脚本先采集 Canvas、Ed 和对应年份的 Handbook，分析阶段只接收采集结果，不需要操作浏览器。所有模型共享同一提示词、课程数据和输出契约：

- 实际提示词及 Schema 由 `scripts/lib/course-analysis.mjs` 生成；字段含义见 [课程 JSON](course-json.md)。
- 模型根据上下文识别同一考核、分数、权重、父子关系和规则；证据足够就填写，不套特定课程规则。
- 最多两级，汇总和子项不能重复计分；bonus、替代考试和 hurdle 单独处理。
- 原生 Schema 或 JSON 模式只约束输出格式；本地仍会校验课程身份、父子关系等业务规则。失败时携带原输出和错误进行修复，整个分析最多两次调用。
- 模型收到的资料包含个人课程及成绩，只发往用户配置的模型服务；原始响应和错误保存在忽略的 `.local` 目录，不提交 Git。

同一提示词并不保证不同服务完全同条件：模型、工具执行环境、输出约束能力和计费方式可能不同，实验应逐项注明。

来源分工：Handbook 提供同年同学期的考核框架、权重和 hurdle；Canvas 提供具体考核、截止与提交信息；Ed 补充规则及已发布成绩。缺少某个来源时仍可使用其他来源，不能虚构来源。模型按实际含义分类并判断跨平台重复项；代码校验层级和可确定的计分规则，不按课程代码或名称硬编码。
