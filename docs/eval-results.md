# 课程分析评测结果

用 [课程分析评测](eval-format.md) 的脚本对真实采集数据跑出的结果。这里只记课程代码和汇总指标；逐次运行的原始回复、最终 document 和标准答案含成绩，只留在本机 `.local/eval/`，不入库。

> **先读这一条：** 这里的「准确率」衡量的是**和之前一次模型输出的一致程度**，不是和人工核对过的真实答案比对。导出页面修正时（2026-10-30）页面里没有任何修正，所以标准答案就是桌面上那份早先的模型输出原样，未经人工核对。详见下面的「局限」。

## 基线

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-10-30（AEDT 00:45 开始，两次调用并行，分别用时 6 分 18 秒和 3 分 19 秒） |
| 代码版本 | `8964477`（`main`，含 #257 评测脚本） |
| 服务商 / 模型 | `deepseek` / `deepseek-flash`（命令行显式传入，与代码里 DeepSeek 的默认模型相同；密钥来自 `DEEPSEEK_API_KEY`，本机没有保存的模型设置） |
| 每门课次数 N | 5 |
| 标准答案 | `.local/eval/gold/`，每门课取桌面上最新一份有效课程 JSON；没有页面修正可合并 |
| 重跑 | 无，两次调用都一次跑完，没有 429 或超时 |

### 输入

每门课用产生其标准答案的那次采集作为输入：

| 采集 run | 课程 | 说明 |
| --- | --- | --- |
| `93c0e78d` | COMP20003 | 这个 run 只有这一门课；当时采集为部分完成 |
| `cfe27abb` | COMP20008、MAST10007、MUSI20163 | 这个 run 里也有 COMP20003 的数据，但 COMP20003 的标准答案不是它产生的，所以不评（见决定 #263） |

命令：

```bash
node scripts/eval-course-analysis.mjs --run .local/lms/runs/93c0e78d --gold .local/eval/gold \
  --n 5 --provider deepseek --model deepseek-flash --out .local/eval/results/baseline-93c0e78d
# 标准答案子目录只放 COMP20008、MAST10007、MUSI20163 三个文件
node scripts/eval-course-analysis.mjs --run .local/lms/runs/cfe27abb --gold .local/eval/gold-cfe27abb \
  --n 5 --provider deepseek --model deepseek-flash --out .local/eval/results/baseline-cfe27abb
```

第二次调用的汇总里 COMP20003 列为「跳过：没有标准答案文件」，这是有意的。

### 总体指标

合计按各门课的计数相加后再除（`summariseOverall`），不是四个百分比的平均。

| 课程 | 标准答案考核数 | 运行 | 有结果 | 字段准确率 | 召回 | 精确 | 单元格一致 | 与首次相同 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| COMP20003 | 20 | 5 | 5 | 80.1% | 85.0% | 76.6% | 24.4% | 20.0% |
| COMP20008 | 10 | 5 | 5 | 91.6% | 98.0% | 98.0% | 78.9% | 20.0% |
| MAST10007 | 8 | 5 | 5 | 96.7% | 100.0% | 100.0% | 91.7% | 20.0% |
| MUSI20163 | 8 | 5 | 5 | 66.1% | 70.0% | 75.7% | 68.1% | 20.0% |
| **合计** | 46 | 20 | 20 | **83.0%** | **87.8%** | **84.9%** | **55.6%** | **20.0%** |

- 「与首次相同」20.0% 表示每门课只有第 1 次和自己相同：第 2–5 次规范化后都和第 1 次不完全一样。同一输入、同一模型，5 次结果没有两次完全一致。
- COMP20003 的单元格一致只有 24.4%：20 个考核 × 9 个字段里，大多数格子在 5 次运行之间至少有一次取值不同。

## 局限

- **标准答案不是人工核对的真值。** 2026-10-30 从浏览器导出页面修正时，修正、手动考核和排序都是空的（从重置标记看，页面数据像是在 2026-10-28 被清空过，未确认），所以标准答案 = 桌面上早先一次模型整理的课程 JSON 原样。这里的「准确率」「召回」「精确」衡量的是本次 `deepseek-flash` 与那次早先模型输出的一致程度，不能说明哪一边是对的：数字低可能是这次错了，也可能是标准答案错了，也可能两种整理方式都合理。
- 样本很小：4 门课、1 名学生、每门课只有一次采集；只代表这几门课在这个时间点的数据。
- COMP20003 的那次采集是部分完成，输入本身不完整；它的指标同时反映了输入缺失。
- N = 5，一致性指标（单元格一致、与首次相同）的波动会很大，不同日期重跑结果可能不同。
- 只跑了 `deepseek-flash` 一个模型，没有和其他模型或服务商对比。
- 打分规则本身的局限（名称配对、`due` 只比日期部分、`name` / `rule` / `sources` / `materials` 不打分）见 [eval-format.md](eval-format.md#局限)。
