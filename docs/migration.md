# 本地数据和迁移

旧原型数据已经移到 `.local-backups/20261028-160949/`：包括原 `.local/lms` 和本项目写入桌面四门课程目录的 `分数结构*.json`。备份与 `.local/` 都被 Git 忽略，未删除其他桌面文件。旧 JSON 与新契约不同，不自动转成新格式或混入新结果；需要时可从备份手动恢复。

当前浏览器首次重新加载新前端时，会先把旧选课、排期、修改、手动条目和排序备份到 localStorage 的 `coursework.backup-before-canonical-v1`，再清除这些旧数据。主题和其他偏好保留；无法保存备份时不会主动清除。此步骤只在该浏览器运行一次。

运行 `npm run dev` 并刷新页面，然后按原流程同步并选择课程。agent 输出符合 v1 契约的 JSON 后，程序校验再展示；旧结果、格式错误或课程 ID 不符的文件不作为新结果。用户的修改、新增、排序和隐藏分别保存在浏览器的本地存储，原同步 JSON 不被修改；后续同步需要 agent 保持考核 ID 稳定才能应用已有覆盖。

同步仍是 Mac / Edge / Codex 的现有实验性实现；浏览器互斥、速度、其他平台和模型尚未重新验证。此次遵照用户要求不自行测试。
