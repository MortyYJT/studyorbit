## 结果及修正

- COMP20003：首次结果把 Ed A1 的 [已移除] 错写为 [已移除]。已将 Ed 目录和成绩按 lesson ID 关联后供模型使用，并在可唯一对应 Ed 来源且不存在匹配 Canvas 成绩时，检查同一来源的分子与分母。重新采集并分析一次后，A1 [已移除]、A2 [已移除]、A3 满分 15，A3 实际得分仍因 403 未取得；权重为作业 40%、Workshop 5%、期中 10%、期末 45%。第二次耗时 119.8 秒，其中分析 111.6 秒；输入 12,940、输出 21,200 Token。第二次结果没有单列 Canvas 的 All 12 Workshops Completed 0.04 分条目，需要后续核对是否影响汇总。不能声称已解决所有跨平台成绩错误。
- COMP20008：A1 15%（[已移除]）、A2 35%、期末 50%；Workshop bonus 上限 2。模型记录连续考核和考试的 hurdle。
- MAST10007：书面作业 15%、期中 10%、机考 15%、期末 60%；四个作业子项每项 3.75%。用户已确认此前对四项等权和 COMP20008 考试数字的判断；此确认不推广到其他课程。
- MUSI20163：课堂参与 50%、两个表演合计 35%、论文 15%，有出勤及提交 hurdle。Handbook 本次读取成功；Ed 未找到不等于同步失败。
